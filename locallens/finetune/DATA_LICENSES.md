# Data and model licences for the fine-tune

The rule for this project: build for commercial use. Training data may only be our own synthetic data or data under
MIT, BSD, Apache-2.0, CC0, CC BY or GODL-India. Anything else is evaluation-only, or not used at all.
Checked on 2026-10-28; where a licence could not be confirmed from the official source, it says so and the data is **not used**.

## Training data: only our own

| Data | Source | Licence | Used for |
|---|---|---|---|
| `finetune/data/train.jsonl`, `val.jsonl` (about 7.6k + 1.1k examples) | generated by `finetune/synth.py`: our own templates, our own word lists (Indian city, state and category names, retail terms), random schemas | ours; no third-party data is in it | training and validation |

The question templates and vocabulary were written by the project developer. Place names, product categories and brand
names in the word lists are ordinary facts and names, used only as example values; no text is copied from any dataset.

## Evaluation-only data (never used for training, never stored in git)

| Data | Source | Licence | Used for |
|---|---|---|---|
| UCI Online Retail II | https://archive.ics.uci.edu/dataset/502/online+retail+ii | CC BY 4.0 (stated on the page; attribution required) | `eval/cross_online_retail.py`, a schema the model never saw |
| UCI Wholesale customers | https://archive.ics.uci.edu/dataset/292/wholesale+customers | CC BY 4.0 (stated on the page; attribution required) | `eval/cross_wholesale.py`, a schema with no date column |

Attribution: Chen, D. (2015). Online Retail II [dataset]. UCI Machine Learning Repository. Cardoso, M. (2013). Wholesale customers [dataset]. UCI Machine Learning Repository.
Both are downloaded by `finetune/fetch_external.py` into `finetune/external/`, which git ignores.

## Considered and NOT used

| Data | What we found | Decision |
|---|---|---|
| data.gov.in (GODL-India) retail price data | the API answers "Authorization field missing": a free registered key is needed | not used. Add it later by registering a key (training would be allowed: GODL-India) |
| nvBench (https://github.com/TsinghuaDatabaseGroup/nvBench) | its README says MIT, but the data is built from Spider databases and queries; Spider's data licence is CC BY-SA 4.0 (from memory, not re-checked here). The repo has no LICENSE file (404) | not used: unclear whether the MIT label holds. Treat as evaluation-only |
| WikiSQL (https://github.com/salesforce/WikiSQL) | the repo LICENSE is BSD-3-Clause; the README does not state a separate data licence; the tables are Wikipedia, not retail | not used: little retail value, data licence not confirmed |
| Spider, SParC, CoSQL | believed CC BY-SA 4.0 | evaluation-only if ever used; not used |
| Olist, Rossmann, Instacart, NLV, Quda, Makadi | licences not checked (Kaggle terms, several are non-commercial) | not used |
